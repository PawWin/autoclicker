The first release of **Tap**, a small Rust autoclicker with a native Slint interface.

- Minimal warm-white interface with orange accents.
- Adjustable click interval from 10 to 60,000 ms, with quick presets.
- Left, right, and middle mouse buttons.
- Repeat until stopped or stop after a chosen number of clicks.
- Three-second countdown, live click counter, and interruptible Stop.
- Global F6 start/stop where supported.

### Downloads

- **Windows x64:** download `Tap-0.0.1-windows-x86_64.exe` and double-click it. Portable application, no installer required.
- **Linux x64:** download `Tap-0.0.1-linux-x86_64.AppImage`, make it executable, and run it:

  ```sh
  chmod +x Tap-0.0.1-linux-x86_64.AppImage
  ./Tap-0.0.1-linux-x86_64.AppImage
  ```

If FUSE is unavailable, run the AppImage with `--appimage-extract-and-run`.

`SHA256SUMS.txt` contains checksums for both downloads. Source archives are available below; the project is licensed GPL-3.0-only.

### Platform notes

Linux X11 supports global F6. On Wayland, use the in-app Stop button; input injection requires compositor support and may be limited to XWayland apps. Windows binaries are unsigned, so Windows may display a SmartScreen prompt. Timing is best-effort and includes input backend overhead.

### Build and validation

Built locally from tag `v0.0.1` with Rust 1.99.1. Linux was compiled against Ubuntu 22.04 (glibc 2.35). Windows was cross-compiled for `x86_64-pc-windows-msvc` with a statically linked C runtime. The Linux AppImage opened successfully on Linux, and the Windows executable opened under Wine. Five engine tests pass; native Windows interaction is not yet verified. These binaries were built without GitHub Actions.
