Tap 0.0.2 adds native Wayland support and faster click intervals.

- Native Wayland clicks on niri and Hyprland through `wlr-virtual-pointer`, without root access or an input helper daemon.
- Automatic global shortcut setup on niri and Hyprland. Tap detects existing bindings and offers another function key when F6 is taken.
- Start/stop commands for compositor bindings and scripts: `--toggle` and `--stop`.
- Click intervals from **1 to 60,000 ms**, with 1 ms and 5 ms presets. Timing remains best-effort and includes input backend overhead.

### Downloads

- **Windows x64:** download `Tap-0.0.2-windows-x86_64.exe` and double-click it. Portable application, no installer required.
- **Linux x64:** download `Tap-0.0.2-linux-x86_64.AppImage`, make it executable, and run it:

  ```sh
  chmod +x Tap-0.0.2-linux-x86_64.AppImage
  ./Tap-0.0.2-linux-x86_64.AppImage
  ```

If FUSE is unavailable, add `--appimage-extract-and-run`. `SHA256SUMS.txt` contains checksums for both downloads.

### Platform notes

Windows and Linux X11 support global F6. On niri and Hyprland, Tap sets up compositor shortcuts automatically and preserves existing bindings. niri requires version 25.02 or newer and a writable active configuration; Hyprland requires the virtual pointer protocol. Other Wayland compositors may work if they expose that protocol. Unsupported compositors report an error. Windows binaries are unsigned. macOS binaries are not included.

### Build and validation

Built locally with Rust 1.99.1 from the latest main code plus the 0.0.2 version update. Linux targets Ubuntu 22.04 (glibc 2.35); Windows targets `x86_64-pc-windows-msvc` with a statically linked C runtime. Formatting, Clippy, and all 17 tests pass. The packaged Linux AppImage opened on Linux, and the Windows executable opened under Wine. AppImage contents and SHA-256 checksums were verified. Native Windows interaction has not been verified. These binaries were built without GitHub Actions.
